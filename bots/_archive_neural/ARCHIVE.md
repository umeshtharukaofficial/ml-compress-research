# Neural Research Archive

This directory serves as the static frozen history for all deep learning models, training scripts, parameters, and networks (RNN, GRU, Transformers) evaluated in early stages of the project.

Benchmarks between 2026-07-19 13:57 and subsequent commits are preserved under `experiments/logs/_quarantine/` due to a losslessness parsing bug. 

The project has transitioned to **Pure-Math Domain-Specific Compression** methodologies using fast columnar encodings, Gorilla XOR representations, and Finite State Entropy (FSE) backends.
