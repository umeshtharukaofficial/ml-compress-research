# Milestones

Track of major project milestones for ml-compress-research.

- **Week 1**: Baselines complete on all 4 domains.
- **Week 4**: First neural predictor beats gzip on ratio (any domain).
- **Week 8**: First neural predictor beats zstd-19 on ratio (any domain).
- **Week 12**: Quantized + ONNX pipeline, < 5 MB model, < 200 MB RAM.
- **Week 20**: Rust runtime, ≥ 20 MB/s decompress on 1 CPU core.
- **Week 30**: Full benchmark paper draft in `paper/main.tex`.
- **Week 40**: Preprint uploaded to arXiv (bot-18 prepares the tarball).
- **Week 52**: v1.0 release, blog series complete, repo archived-ready.
